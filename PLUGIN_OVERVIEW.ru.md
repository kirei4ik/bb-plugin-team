# Team

Команды агентов по ролям для bb: руководитель планирует и принимает работу,
исполнители — разработчики, дешёвый младший разработчик для простых задач,
тестировщики, писатели — отчитываются ему. Несколько команд в проекте, из
шаблонов.

## Зачем

Многоагентная работа в bb делается руками: промпты ролей с нуля, треды по
одному, ID тредов вручную, пакеты работ в переписке. Team превращает это в
шаблон, короткий конфиг и одну кнопку.

## Как это работает

1. Панель Team показывает проекты группами «с командами», «можно создать»,
   «сейчас нельзя» (с причиной) и поиск.
2. Выберите шаблон (разработка, QA, документация, менеджерская или свой),
   поправьте роли, провайдеров и модели — и создайте команду. Выключенный
   провайдер блокирует создание заранее.
3. Руководитель получает состав команды; исполнители — его дочерние треды с
   названиями `👥 Разработчик` (или `👥 core · Разработчик`, если команд
   несколько).
4. Работайте из дерева в панели или из CLI: сообщения ролям по имени, пакеты
   работ с учётом, пауза, остановка, новые исполнители.

## Возможности

- **Несколько команд в проекте**: у каждой свой `.bb/teams/<команда>.yaml`,
  своя секция сайдбара, свои пакеты и пауза.
- **Экономная команда по умолчанию**: руководитель на сильной модели,
  разработчик, джун на дешёвой модели, тестировщик; короткие встроенные
  промпты — сначала план, распределение по сложности, маленькие диффы и отчёты.
- **Шаблоны** общие для проектов: редактор в Настройках → Team, новый шаблон из
  видов ролей с готовыми промптами, сохранение работающей команды как шаблона.
- **Добавление исполнителей**: новая роль или свободный тред проекта.
- **Пакеты работ**: исполнитель переводит в ревью, принимает только
  руководитель.
- **Помощники**: треды, которые агент создаёт под ролью, видны под ней.
- **Пауза**, **notifyOn**, **doctor**, **replace** с передачей дел.
- **Вне git по умолчанию**: версионирование включается для каждой команды.

## Команды

`bb team init | create | list | status | add-role | version | tell |
task add/list/update/done/remove | report | doctor | replace | stop | pause |
resume | retitle | template list/show/save/delete` — все с `--team`,
`--project` и `--json`.

Включается по проекту: проекты без конфигов команд не затрагиваются.
